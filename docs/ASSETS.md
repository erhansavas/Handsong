# Assets

Every file that ships in the app is listed here with its origin, generator and licence.

| File | Origin | Generator | Licence |
|---|---|---|---|
| `instrument.hsmesh` | First-party. No scan and no measured data from any product | `model/instrument/export.py`, `model/instrument/bake.py` (Blender Cycles) | Apache-2.0 |
| `studio.hsenv` | First-party, the studio light | `model/instrument/cook_env.py` | Apache-2.0 |
| `grade.hslut`, `blue_noise.hsnoise` | First-party | `model/instrument/cook_grade.py` | Apache-2.0 |
| `score/*.caf` | First-party, composed from nothing. Reads no audio and no reference | `sound/compose.py` | Apache-2.0 |
| `Assets.car`, `Handsong.icns`, `menubar.png` | First-party mark | `tools/icon/make_icon.py`, `actool`, `iconutil` | Apache-2.0 |
| `docs/media/*.png` | First-party renders of the app | `build/Handsong.app --test experience` | Apache-2.0 |
| `docs/media/icon.png` | First-party mark | `tools/icon/Handsong.icon`, `ictool` | Apache-2.0 |
| `shaders.metallib` | First-party | `shaders/*`, `xcrun metal` | Apache-2.0 |

The words on screen use the system's own serif, drawn at run time. No font file ships. All of the above except the tracked `studio.hsenv`, `grade.hslut` and `blue_noise.hsnoise` are generated by `tools/build_assets.sh` and are not kept in Git.

with GPLv3. Files they produce are not covered by Blender's licence. Checked 2026-11-02 at https://www.blender.org/about/license/.
